# SPEC 03 — Civilizacion como seccion y acoples

Civilizacion no es un nodo. Es el par C = (W_C, F_C).
W_C = soporte geografico x [tmin, tmax].
F_C(d) = nodos cuyo intervalo solapa el soporte y cuya region esta en C.
Un nodo en dos civilizaciones es un puerto.

Acoples: war, conquest, treaty, trade, exchange, translation, diffusion,
conversion, diaspora, succession, fusion, contact, expansion, coexist.

join(Ci, Cj, t) solo con acoples cuyo intervalo contiene t.
